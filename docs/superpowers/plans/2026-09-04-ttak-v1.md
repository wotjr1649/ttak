# TTAK v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship TTAK v1 — a two-surface plugin for Claude Code and Codex CLI: an opt-in operating discipline injected by lifecycle hooks, and one model-invocable audience-adaptive explainer skill.

**Architecture:** One Node CommonJS hook runtime (`hooks/ttak.cjs`, standard library only, zero dependencies) reads three canonical policy files and a one-key state file, and injects composed policy text on `SessionStart` and `SubagentStart` when the user has turned TTAK on. `UserPromptSubmit` intercepts three exact-match control prompts and blocks them from the model. A separate self-contained `SKILL.md` provides the explainer and does not depend on the hook state. Both hosts consume the same runtime, the same policy text, and the same skill; only the manifests differ.

**Tech Stack:** Node.js (stdlib only, CommonJS `.cjs`), `node:test` for deterministic tests, Python 3 for the cross-host conformance runner, Git for Windows with `core.autocrlf=true` as the hostile default the repo must survive.

**Spec:** `docs/superpowers/specs/2026-09-04-ttak-design.md`, governed by `docs/TTAK_Plugin_Product_Definition_v0.2_EN.md` — the v0.1 candidate with `docs/TTAK_Plugin_Product_Definition_v0.2_AMENDMENT_EN.md`.

## Global Constraints

- **Zero runtime dependencies.** `hooks/ttak.cjs` uses only `node:fs`, `node:path`, `node:os`. No package.json dependency section for the shipped plugin. Test and eval tooling is dev-only and must not be required to run the plugin.
- **No network, no telemetry, no analytics, no transcript parsing.** The runtime reads only its own plugin root and the host-provided plugin data directory.
- **Plugin root is read-only at run time.** Every mutable write goes to `<PLUGIN_DATA>`.
- **Never block an ordinary prompt.** Any internal failure on an ordinary prompt must fail open and let the prompt proceed. Exit code 0.
- **Never emit raw prompt text, filesystem paths, state contents, or exception detail** in any user-visible message.
- **Line endings are LF everywhere.** `.gitattributes` carries `* text=auto eol=lf`. No shipped file may contain a `\r` byte.
- **Every `SKILL.md` description is quoted or a block scalar.** `anthropics/claude-code#80890` silently skips a `SKILL.md` with CRLF and an unquoted description containing `": "`.
- **One license string, MIT, identical everywhere it is declared** — `LICENSE`, `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, both marketplace files if they carry a license field, and `skills/ttak-explain/SKILL.md` frontmatter.
- **Provider-neutral text.** The strings `Claude`, `you are Claude`, `Anthropic`, `OpenAI`, and `Codex` must not appear in `policy/*.md` or in the body of `skills/ttak-explain/SKILL.md`. Say "the model" and "the host".
- **No host-specific invocation syntax inside instruction text.** `/ttak:ttak-explain` and `$ttak:ttak-explain` belong in `README.md`, nowhere else.
- **Default OFF.** Absent state means off. Installing the plugin must inject no policy.
- **Plugin name:** `ttak`. **Skill directory and frontmatter name:** `ttak-explain`. **Version:** strict semver, starting `0.1.0`.
- **The test runner is guarded on this machine.** A hook rejects a bare test-runner invocation;
  every run must carry `--test-concurrency=1`. Confirmed by the guard blocking the controller's
  own command. Using the flag is compliance, not a workaround.
- **Bash heredocs collapse a doubled backslash on this host.** Writing a file that contains two
  backslashes through a heredoc produces one, silently corrupting regular expressions and path
  patterns. Use the file-writing tool for any file containing a backslash, and verify the written
  bytes afterwards. Observed in Task 1.
- **Commit style:** conventional commits. Commit at the end of every task, never mid-task.

```js
const path = require('node:path');
```

```js
// tests/lint/check-hygiene.cjs
const fs = require('node:fs');
const path = require('node:path');

const SKIP_DIRS = new Set(['.git', 'node_modules', 'assets', '.claude', '.superpowers']);
const TEXT_EXT = new Set(['.md', '.json', '.cjs', '.js', '.py', '.jsonl', '.yaml', '.yml', '']);
const PROVIDER_WORDS = /\b(Claude|Anthropic|OpenAI|Codex)\b/;
// Instruction text must stay provider-neutral. README and manifests may name hosts.
const NEUTRAL_GLOBS = [/^policy[/\\]/, /^skills[/\\].*SKILL\.md$/];

function walk(dir, root, out = []) {
  for (const e of fs.readdirSync(dir, { withFileTypes: true })) {
    if (e.isDirectory()) {
      if (SKIP_DIRS.has(e.name)) continue;
      walk(path.join(dir, e.name), root, out);
    } else {
      out.push(path.relative(root, path.join(dir, e.name)).split(path.sep).join('/'));
    }
  }
  return out;
}

function checkHygiene(root) {
  const files = walk(root, root);
  const crFiles = [];
  const licenseMismatch = [];
  const providerLeaks = [];

  for (const rel of files) {
    const ext = path.extname(rel);
    if (!TEXT_EXT.has(ext)) continue;
    const buf = fs.readFileSync(path.join(root, rel));
    if (buf.includes(0x0d)) crFiles.push(rel);
    const text = buf.toString('utf8');

    if (ext === '.json') {
      const declared = text.match(/"license"\s*:\s*"([^"]*)"/g) || [];
      for (const d of declared) if (!/"MIT"/.test(d)) licenseMismatch.push(`${rel}: ${d}`);
    }
    if (rel.endsWith('SKILL.md')) {
      const fm = text.match(/^---\n([\s\S]*?)\n---/);
      if (fm && /^license:/m.test(fm[1]) && !/^license:\s*MIT\s*$/m.test(fm[1])) {
        licenseMismatch.push(`${rel}: frontmatter license`);
      }
    }
    if (NEUTRAL_GLOBS.some((g) => g.test(rel)) && PROVIDER_WORDS.test(text)) {
      providerLeaks.push(rel);
    }
  }
  return { crFiles, licenseMismatch, providerLeaks };
}

module.exports = { checkHygiene };
```

## Task 2: State — read, write atomically, and classify every failure

**Files:**
- Create: `hooks/ttak.cjs`

**Interfaces:**
- Produces:
  - `dataRoot()` → `string | null`. Resolves `PLUGIN_DATA` then `CLAUDE_PLUGIN_DATA`. Returns `null` when neither is set.
  - `readState()` → `{ status: 'on' | 'off' | 'absent' | 'invalid' | 'unavailable' }`. Never throws.

`absent` means "no state yet, therefore OFF". `unavailable` means "cannot even tell", which is also OFF for injection but is not repairable by a write.

```js
// hooks/ttak.cjs
'use strict';
const fs = require('node:fs');
const path = require('node:path');

function dataRoot() {
  return process.env.PLUGIN_DATA || process.env.CLAUDE_PLUGIN_DATA || null;
}

function statePath() {
  const root = dataRoot();
  return root ? path.join(root, 'state.json') : null;
}

function readState() {
  const p = statePath();
  if (!p) return { status: 'unavailable' };
  const leaf = path.dirname(p);
  let leafStat = null;
  try { leafStat = fs.statSync(leaf); }
  catch (e) {
    if (e.code !== 'ENOENT') return { status: 'unavailable' };
    // Leaf missing: absent only when the parent exists. The host may not
    // pre-create <plugin>-<marketplace>/ on a fresh profile.
    try { return fs.statSync(path.dirname(leaf)).isDirectory() ? { status: 'absent' } : { status: 'unavailable' }; }
    catch { return { status: 'unavailable' }; }
  }
  if (!leafStat.isDirectory()) return { status: 'unavailable' };

  let st = null;
  try { st = fs.statSync(p); }
  catch (e) { return e.code === 'ENOENT' ? { status: 'absent' } : { status: 'unavailable' }; }
  if (!st.isFile()) return { status: 'unavailable' };

  let raw;
  try { raw = fs.readFileSync(p, 'utf8').replace(/^﻿/, ''); }
  catch { return { status: 'unavailable' }; }

  let parsed;
  try { parsed = JSON.parse(raw); } catch { return { status: 'invalid' }; }
  if (!parsed || typeof parsed.enabled !== 'boolean') return { status: 'invalid' };
  return { status: parsed.enabled ? 'on' : 'off' };
}

function writeState(enabled) {
  const p = statePath();
  if (!p) return { ok: false };
  const leaf = path.dirname(p);
  try {
    if (!fs.existsSync(leaf)) {
      // Only create the leaf, and only when its parent already exists.
      if (!fs.statSync(path.dirname(leaf)).isDirectory()) return { ok: false };
      fs.mkdirSync(leaf);
    } else if (!fs.statSync(leaf).isDirectory()) {
      return { ok: false };
    }
    if (fs.existsSync(p) && !fs.statSync(p).isFile()) return { ok: false };

    const tmp = path.join(leaf, `.state.${process.pid}.tmp`);
    fs.writeFileSync(tmp, JSON.stringify({ enabled }) + '\n', 'utf8');
    fs.renameSync(tmp, p);
    const back = readState();
    return { ok: back.status === (enabled ? 'on' : 'off') };
  } catch { return { ok: false }; }
}

module.exports = { dataRoot, statePath, readState, writeState };
```

- [ ] **Step 3: Write the policy files**

`policy/precedence.md` — this is the substantive difference from every predecessor. It tells the model where this text ranks. Provider-neutral.

```markdown
# Precedence

This guidance ranks below the host's own system and developer instructions, below any repository or
project instruction file, and below the user's explicit request. Where it conflicts with any of
them, they win and this yields to them without argument.

It is guidance the model interprets. It is not a guard, not an enforcement mechanism, not a security
control, and not a correctness guarantee. Permissions, sandboxing, approval prompts and policy
controls remain the only things that actually constrain what happens.

Simplicity never outranks correctness, safety, completeness, or an explicit requirement. Character
and brevity never outrank task quality.
```

`policy/invariants.md` — engineering discipline, carrying the protected nouns verbatim and the two
requirements added in the amendment.

```markdown
# Invariants

- Understand the request and the flow it touches before changing anything. Inspect the callers and
  shared paths a change crosses before changing a shared contract.
- When only analysis, explanation, reporting or review was asked for, do not mutate code and do not
  force an implementation.
- Skip features, files, options and scaffolding the requested outcome does not need.
- Prefer, in order: existing project code, the standard library, native platform features, an
  already-installed dependency, then the smallest new implementation that fully satisfies the
  requirement.
- Do not add a single-use abstraction, future-only configuration, wrapper, factory, or file split
  without a present reason.
```

```js
// add to hooks/ttak.cjs
const NOTICE = 'TTAK is installed and off. Send the prompt "ttak on" to turn it on for this host, "ttak off" to turn it off.';
const ERR = 'TTAK could not read or write its saved setting. Nothing was changed.';

function noticeFlagPath() {
  const root = dataRoot();
  return root ? path.join(root, '.notified') : null;
}

function emit(event, text) {
  return { stdout: JSON.stringify({ hookSpecificOutput: { hookEventName: event, additionalContext: text } }), exit: 0 };
}
function block(reason) { return { stdout: JSON.stringify({ decision: 'block', reason }), exit: 0 }; }
const NOOP = { stdout: '', exit: 0 };

function handle(input) {
  try {
    const event = input && input.hook_event_name;
    if (event === 'UserPromptSubmit') {
      const cmd = parseControl(input.prompt);
      if (!cmd) return NOOP;
      if (cmd === 'status') {
        const s = readState();
        if (s.status === 'unavailable' || s.status === 'invalid') return block(ERR);
        return block(`TTAK saved setting: ${s.status === 'on' ? 'ON' : 'OFF'}. It applies from the next clean session boundary; resumed or compacted contexts may retain earlier text.`);
      }
      const ok = writeState(cmd === 'on').ok;
      return block(ok ? `TTAK saved setting: ${cmd === 'on' ? 'ON' : 'OFF'}.` : ERR);
    }

    if (event !== 'SessionStart' && event !== 'SubagentStart') return NOOP;

    const s = readState();
    if (s.status !== 'on') {
      if (event !== 'SessionStart' || s.status === 'unavailable') return NOOP;
      const flag = noticeFlagPath();
      if (!flag || fs.existsSync(flag)) return NOOP;
      try { fs.writeFileSync(flag, ''); } catch { return NOOP; }
      return emit(event, NOTICE);
    }

    const text = compose(event === 'SubagentStart' ? 'subagent' : 'main');
    return text ? emit(event, text) : NOOP;
  } catch { return NOOP; }
}

module.exports.handle = handle;
```

```python
CLAUDE = ["claude", "-p", "--output-format", "json",
```
