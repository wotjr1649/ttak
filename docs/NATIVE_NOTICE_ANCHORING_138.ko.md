# 정확한 보류 반환과 잘못된 근거 부족 판정 — 138

후보 `0.2.0-rc.13+codex.20260912200221`은 한 결함당 한 issue, 짧은 원문 절 인용,
요청에 이미 제시된 초안 주장의 직접 평가를 명시했다. 문자열 대조·수리 조건은
완화하지 않았다. 집중168, 전체 Node45파일 / 573 PASS / 0 skip, Python78,
conformance와 정상 설치·11개 hook 검토를 통과했다. 리터럴 백슬래시-n과 실제
줄바꿈의 정확한 반환은 각각 허용하지만 서로 바꾼 반환은 거부하는 회귀를 추가했다.

Haiku는 실측 수치 외에 전체 초안 문서도 없어 평가할 수 없다고 잘못 제안했다.
실제 독립 검토자는 같은 잘못된 요구를 승인했다. 원래 요청 자체가 T1 reads A라는
주장을 주고 이를 S1과 대조하도록 요구한다. S1의 T1 guard는 B 읽기, 쓰기는 A다.
이 주장 평가에 별도 전체 초안이 필수라는 조건은 없다. 따라서 미해결 항목2와
그에 대한 검토자 설명은 의미 FAIL이며, 요청된 정정도 누락됐다.

실제 native 제출·반환·최종 본문·retained state 재생은 모두 일치했다. 부모가 부연을
추가한 뒤 Stop의 한 번 교정으로 승인된 본문을 정확히 다시 전달했다. 이 기계적
PASS는 잘못된 내용을 올바르게 전달했다는 뜻일 뿐, 의미 판정의 PASS가 아니다.
